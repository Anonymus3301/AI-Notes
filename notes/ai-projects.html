AI Projects to Build

Three portfolio projects that demonstrate retrieval, reliable tool use, and practical data analysis. Each plan is broken into four weekly milestones; check off your progress as you build.

0 of 15 tasks complete

Ask questions about uploaded documents and get evidence-linked answers instead of hunting through pages.

  • RAG
  • Evaluation
  • Source citations

What to build

Accept one or more PDFs, extract and chunk the text, index embeddings, retrieve relevant passages for each question, and answer with document and page references. Include a clear “not found” response when evidence is missing, plus chat history for follow-ups.

Suggested stack and stretch goals

Suggested stack

Python · PyMuPDF or pypdf · embeddings · Chroma (then pgvector) · LLM API · FastAPI · Streamlit · Docker

Stretch goals

  • Compare hybrid keyword and vector retrieval with a re-ranker.
  • Support two answer languages and side-by-side document comparison.
  • Track answer quality, cost, and latency in a small dashboard.
What to discuss in interviews

Use evaluation results to explain chunking and retrieval choices, how you reduce unsupported answers, how the system behaves when evidence is absent, and what would change at a much larger corpus size.

Four-week build plan

Answer support questions from an approved knowledge base, perform a small set of verified actions, and hand off when needed.

  • RAG
  • Tool calling
  • Safety and escalation

What to build

Ground policy answers in help-center content. Add mock order-status and return-request tools; verify ownership and inputs in application code, ask for confirmation before changes, and route uncertain or difficult cases to a person.

Suggested stack and stretch goals

Suggested stack

Python · LLM tool calling · SQLite or Postgres mock orders · Chroma knowledge base · FastAPI · chat UI · structured logs

Stretch goals

  • Remember conversations across sessions with user consent.
  • Detect frustration and route the conversation to support staff.
  • Add an admin view of conversations and tool activity, or multilingual replies.
What to discuss in interviews

Explain where authorization, validation, and confirmation happen; how answers stay grounded in policy; and one failure found and fixed by your test conversations.

Four-week build plan

Let people ask questions about spreadsheets in plain language and inspect the numbers, chart, and analysis behind each answer.

  • Python and data
  • Constrained execution
  • Charts

What to build

Accept CSV or Excel files, show detected columns and sample rows, produce Pandas or SQL analysis, and present the result with a useful chart and the generated query or code. Keep execution constrained and make errors understandable.

Suggested stack and stretch goals

Suggested stack

Python · Pandas · DuckDB or SQLite · LLM API · Plotly or Matplotlib · Streamlit · Docker

Stretch goals

  • Join multiple related files or export a PDF insights report.
  • Support follow-up questions about earlier results.
  • Compare SQL and Pandas analysis on a known test set.
What to discuss in interviews

Show how you limit generated code, how you handle ambiguous questions and messy data, and how measured accuracy improved after fixing a test failure.
